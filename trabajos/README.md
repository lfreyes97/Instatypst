# trabajos

Piezas terminadas o en curso hechas con el paquete: series de láminas,
carruseles, carteles. Aquí van todos los trabajos nuevos, una carpeta por
serie. Los ejemplos que documentan la API viven en `examples/`.

- `campana/` — 21 láminas de la campaña (ver su README).
- `laminas/` — láminas sueltas.
- `ellul-tecnica/`, `ellul-estado-tecnico/` — carruseles sobre Jacques Ellul.
- `vantil-recompensas/` — línea de tiempo sobre Van Til.

Cada `.typ` lleva en su cabecera el comando de compilación (desde la raíz
del repo, `--root .`). Los PNG/PDF generados no se versionan.
